初回デモはこの環境で約7秒でしたが、パッケージ取得にキャッシュを利用しています。人が読む時間や環境準備は含まず、「初めての人が10分で導入できる」という目標の達成証拠にはしません。

## 直した説明

- 必要なPython・Git・ネットワークと、`python` がない場合の案内を追加。
- デモ完了時のファイル、表示の確認箇所、ブラウザでの開き方を明記。
- 自分のプロジェクトの仮想環境へ導入する2つの経路を追加。PyPI未公開であることも明記。
- フォルダ名・import名・配布パッケージ名の違いと、引数なしの検査範囲を説明。
- `denied` / `unknown` / 未インストール / 設定パス / CLIが見つからない場合の対処を追加。
- 終了コード1に変更検出・証拠ファイル欠落も含まれることを反映。不明ライセンスがCIを止める条件の説明を修正。
